# AETHRA 🌧️⛰️

### Machine Learning-Based Landslide Risk Analysis in Uttarakhand

AETHRA is a machine learning project focused on understanding and analyzing landslide risk in Uttarakhand, India, using historical landslide records, rainfall data, and terrain-related information.

## Objective

The project aims to explore environmental factors associated with landslide occurrences and investigate the potential of machine learning techniques for landslide risk analysis.

## Data Sources

- Historical landslide records
- Rainfall data
- Digital Elevation Model (DEM) and terrain information

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- Machine Learning

## Project Status

🚧 Work in Progress — Data preprocessing, feature development, model building, and evaluation are being developed.

## Project Structure

The repository will contain notebooks, source code, datasets or dataset references, visualizations, and project documentation as development progresses.
